# chelsealuther.github.io

Version 5 editorial homepage for GitHub Pages.

Upload the contents of this folder to the root of the repository. The website requires:
- index.html
- styles.css
- script.js
- assets/

BRAND.md and README.md are optional documentation files and do not affect the live site.


## Client testimonial compilation

The Life Coaching section is ready for your compilation video. Add your final video to the `assets` folder using this exact filename:

`client-stories.mp4`

The current `client-stories-poster.jpg` is a temporary poster image. Replace it with a vertical still from the compilation whenever you are ready. The recommended poster ratio is approximately 9:19.
